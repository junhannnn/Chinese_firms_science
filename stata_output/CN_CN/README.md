# CN_CN processed-data availability

Some processed datasets used by the CN_CN analyses are not included in this
public-release repository because the files are too large.

Researchers who need an omitted CN_CN data file may contact the paper's first
author at [junhan.wang@szu.edu.cn](mailto:junhan.wang@szu.edu.cn). Data sharing
remains subject to any applicable access, licensing, and redistribution
restrictions.
