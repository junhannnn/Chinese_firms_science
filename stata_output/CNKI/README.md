# CNKI processed-data availability

Some processed China National Knowledge Infrastructure (CNKI) datasets used by
the analysis are not included in this public-release repository because the
files are too large.

Researchers who need an omitted CNKI data file may contact the paper's first
author at [junhan.wang@szu.edu.cn](mailto:junhan.wang@szu.edu.cn). Data sharing
remains subject to any applicable access, licensing, and redistribution
restrictions.
