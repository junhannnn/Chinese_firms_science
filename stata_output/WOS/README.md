# WOS processed-data availability

Some processed Web of Science (WOS) datasets used by the analysis are not
included in this public-release repository because the files are too large.

Researchers who need an omitted WOS data file may contact the paper's first
author at [junhan.wang@szu.edu.cn](mailto:junhan.wang@szu.edu.cn). Data sharing
remains subject to any applicable access, licensing, and redistribution
restrictions.
