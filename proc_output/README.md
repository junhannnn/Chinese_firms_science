# Python processed outputs

This folder is the expected destination for regenerated Python process outputs.
No Python process-data files are included in the current public bundle because
of their size or applicable access, licensing, and redistribution restrictions.
Researchers who need an omitted file may contact the paper's first author at
[junhan.wang@szu.edu.cn](mailto:junhan.wang@szu.edu.cn).

Included subfolders:

- `CN_CN`
- `CNKI`
- `WOS`

The included analysis-ready data are listed in `../stata_output/README.md` and
`../config/processed_data_manifest.csv`. The inventory contains no Python
process-data files from this folder.
